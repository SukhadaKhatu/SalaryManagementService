# ACME salary management

A React, Express and PostgreSQL demo for exploring and managing compensation across 10,000 synthetic employees.

- [Requirements and scope](REQUIREMENTS.md)
- [Database setup and seed](backend/db/README.md)
- [Backend setup and API](backend/README.md)
- [Frontend setup](frontend/README.md)

Set up and seed PostgreSQL first, start the backend, then start the frontend. This demo has no authentication or authorization and must not be used with real salary data or exposed to untrusted networks.
